# stolikqr

Digital platform for restaurants with interactive menus, online ordering, reservations, and analytics.

## Стек

Next.js (App Router) + TypeScript + Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — страница редиректит на демо-меню ресторана (`/r/demo-restaurant`).

## Текущий статус

MVP интерактивного QR-меню: демо-ресторан, категории, блюда с подробной карточкой и выбором опций. Все данные — локальные mock-данные (`src/data`), без БД, авторизации, оплаты и внешних API.
